# RAG 평가 요약 (발표용)

> **주의:** 모든 정답 라벨은 AI가 작성했고 사람이 검토하지 않았습니다. 답변 품질은 Gemini가 아니라 **학교 GPU의 로컬 모델(Qwen 2.5 7B)** 로
> 측정했습니다. 검색 지표는 "정답 문서·문단을 찾았는가"이고 "최종 답이 맞는가"와는 다릅니다.

## 1. 검색 방식 비교 (100문항, 20개 상황 × 5개 언어, 검증용 세트 v0.2)

| 방식 | Recall@1 | Recall@10 | MRR | nDCG@10 |
|---|---|---|---|---|
| 벡터 검색만 | 0.50 | 0.83 | 0.631 | 0.62 |
| **하이브리드 (현재 운영 방식)** | **0.63** | **0.94** | **0.736** | **0.75** |

출처: `scripts/benchmarks/results/rag_research_heldout.json` (재현 결과 동일). 같은 질문의 5개 언어 버전은 독립적이지 않으므로, 정보 요구
단위로 다시 계산한 하이브리드 MRR의 95 % 구간은 [0.635, 0.825]입니다(질문 단위 계산 [0.663, 0.807]보다 넓음). 실제 PostgreSQL + pgvector
에서도 같은 결과가 나왔습니다(첫 정답 순위 일치 98 / 100).

## 2. 고정된 TEST 세트 (210문항 = 42개 정보 요구 × 5개 언어, 실험 전에 고정)

| 구성 | 정답 근거 문단이 답변 모델에 전달 | 정답 문서가 전달 |
|---|---|---|
| 현재 검색, 질문 재작성 없음 | 64.2 % | 84.2 % |
| **현재 검색 + 질문 재작성(영어·한국어 변형)** | **85.8 %** (+21.6 %p, 95 % 구간 +14.7 ~ +28.4) | **97.4 %** |
| 긴 가이드북 감점(실험) | 63.2 % | 83.7 % → **채택 안 함** |

- 다른 언어로 된 근거(예: 영어 질문 → 한국어 공지): 57.9 % → **84.2 %** (재작성 사용 시).
- 운영 시스템은 이미 Gemini로 질문을 재작성합니다. 따라서 **재작성이 실패할 때**(LLM 장애, 일일 한도 초과) 품질이 떨어지는 점을 감시해야
  합니다.
- 청크 분할 버그로 승인된 문서 본문의 13 %(한국어 유학생 가이드북의 58 %)가 검색되지 않던 문제를 찾아 고쳤고(`CHUNKER_VERSION=v2`),
  스테이징 재색인 후 적용할 예정입니다.

## 3. 답변 평가 (로컬 대리 모델, TEST 210문항)

| 항목 | 검색 사용 | 출처 없이 답변 |
|---|---|---|
| 정답 수치(금액·날짜·기간) 포함률 | **59 %** | 2 % |
| 인용한 출처 문단에 정답 근거 포함 | 73 % | — |
| 다른 언어로 답한 비율 | 0 % | 12 % (영어 질문은 47 %) |
| 출처에 없는 질문: 지어낸 금액 | **0 / 20** | 5개 중 2개 |

- 이전에 발표한 "출처 없으면 0 %"는 가상의 문서로 만든 평가의 한계였습니다. 실제 질문으로 다시 측정하면 2 %입니다.
- 출처끼리 다른 경우(근무 시간 25시간 대 20시간)에 최신 값을 답했지만 충돌 사실은 알리지 않았습니다(개선 과제).

## 4. 안전성

| 검사 | 결과 |
|---|---|
| 미승인·이전 판·취소·보관·만료·시작 전·비활성 출처 문서가 답변에 쓰이는가 | 실제 PostgreSQL에서 8개 상태 모두 **차단** |
| 승인된 문서에 심은 "AI에게 지시" 문장, 시스템 프롬프트 요구 | 차단 장치 전 7 / 11 → 후 **11 / 11** 통과 |
| 잘못된 출처에 붙은 숫자 | 112문장 중 7개를 올바른 출처로 재지정 |

## 5. 아직 말할 수 없는 것

Gemini의 실제 정답률, 사람이 검증한 정확도, 실제 학생 질문에 대한 성능. 준비된 측정 방법과 비용은
`docs/research/rag-v2/ANSWER-EVALUATION.md` §6에 있습니다.
