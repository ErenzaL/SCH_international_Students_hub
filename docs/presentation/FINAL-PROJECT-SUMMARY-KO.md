# SCH 외국인 유학생 허브 — 최종 프로젝트 요약

## 1. 배경과 문제

순천향대학교 외국인 유학생은 비자·체류, 수강신청, 기숙사, 아르바이트 허가, 장학금 정보를 여러 웹사이트와 한국어 공지에서
직접 찾아야 합니다. 정보는 흩어져 있고, 공지는 대부분 한국어이며, 마감일과 수수료처럼 틀리면 불이익이 큰 정보가 많습니다.
일반 챗봇은 그럴듯한 숫자를 지어내고 출처를 밝히지 않습니다.

**목표:** 승인된 공식 자료만 근거로, 5개 언어(한국어·영어·인도네시아어·베트남어·중국어)로 답하고 출처를 보여 주는 서비스. 공지
번역과 외부 정보 수집은 반드시 사람이 검토한 뒤 공개합니다.

## 2. 시스템 구성

- **웹(Next.js) + API(FastAPI)**: Render 무료 요금제, **데이터베이스·인증·저장소**: Supabase(PostgreSQL + pgvector).
- **RAG**: 질문 재작성(Gemini Flash-Lite, 영어·한국어 변형) → 하이브리드 검색(다국어 임베딩 + 전문 검색) → 근거 선택 → Gemini 3.6 Flash
  답변 → 인용·숫자 검사. 승인·최신·유효한 문서만 검색되도록 데이터베이스 뷰에서 강제합니다.
- **Knowledge Center**: 승인된 문서와 원문 보기. **공식 공지**: 검토 후 게시, 번역은 검토자 승인 후 공개(Release 1: 한·영·인니).
- **AI Office**: 14개 전문 창구(안내, 언어별 지원 5, 비자, 학사, TOPIK, 장학, 행사, 취업, 모니터링, 상담 연결). 역할과 금지 행동은 서버가 정합니다.
- **관리자 화면**: 검토, 출처 관리, 에이전트 작업, AI 사용량과 일일 한도.
- 학교 GPU(RTX 4070)는 연구와 무료 번역 초안 실험에만 사용하고, **운영은 학교 컴퓨터에 의존하지 않습니다.**

자세한 그림: `SYSTEM-ARCHITECTURE.md`.

(하루 60회). 최종 릴리스는 로컬에서 테스트를 마쳤고 GitHub 업로드와 배포는 소유자의 한 단계(인증)가 남아 있습니다.
