# AI Office — 14개 에이전트 기능

모든 에이전트의 역할·도구·금지 행동은 서버(`backend/app/services/agents/registry.py`)가 정하고, 화면은 그것을 보여 줄 뿐입니다.
작업은 데이터베이스에 기록되며(재시도 3회, 취소, 시간 초과, 일시정지), 관리자는 작업의 메타데이터만 보고 학생의 글은 보지 않습니다.

**정직한 상태:** 에이전트는 사람이 요청할 때 일합니다. 주간 자동 일정은 구현되어 있지만 운영에서는 **꺼져 있습니다.** 외부에서 찾은
항목은 사람의 승인 없이는 **절대 게시되지 않습니다.**
