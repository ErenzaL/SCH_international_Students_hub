| 분야 | 한계 | 근거 | 중요도 |
|---|---|---|---|
| RAG | 평가 라벨이 AI 작성, 사람 검증 없음 | 데이터셋 카드 | 높음(연구 주장) |
| RAG | Gemini 답변 정확도 미측정(키 없음, 유료 실행 승인 필요) | 로컬 대리 모델로만 측정 | 높음 |
| RAG | 질문 재작성이 실패하면 다른 언어 질문의 근거 전달률 58 % | TEST | 중간 |
| RAG | 긴 문서 안의 규정·각주 문단을 놓침(입학 요강 0 %, 비자 0.56 → 0.82) | TEST | 중간 |
| RAG | 숫자는 맞지만 대상이 틀린 답(학생증 수수료 질문에 외국인등록증 수수료) | 오류 분석 | 중간 |
| RAG | 출처 간 충돌을 알리지 않음 | 근무 시간 사례 0 / 5 | 중간 |
| RAG | 청크 분할 수정(v2) 아직 운영 미적용 | 본문 13 % 검색 불가 | 중간 |
| 번역 | 공지 기계 번역은 한국어·영어·인도네시아어만, 원어민 품질 평가 없음 | Release 1 범위 | 중간 |
| 에이전트 | 주간 자동 일정 꺼짐, 사람이 요청할 때만 동작 | 설정 | 낮음 |
| 외부 출처 | 고용24·공공데이터·사람인 키 없음, 링커리어·버디즈·잡코리아 권한 없음(링크만) | 연동 상태 | 낮음 |
| 인프라 | Render 무료 512 MB 여유 20–50 MB, 첫 접속 약 45초, Supabase 무료는 자동 백업 없음 | 메모리 측정 | 중간–높음 |
| 비용 | 일일 답변 한도는 금액 한도가 아님 | 답변당 약 0.012달러 | 높음 |

## 향후 과제

| 단계 | 과제 |
|---|---|
| **A. 발표 직후** | 운영 모니터링, 실제 버그 수정, Gemini 비용 확인과 예산 알림, 실패 로그 검토, 주간 DB 백업 |
| **B. 다음 학기** | 사람이 검증한 평가 세트, Gemini 답변 품질 평가, chunker v2 재색인, 비자·입학 문단 선택 개선, 출처 충돌 안내, 주간 일정 하나씩 활성화, 번역 품질 평가 |
| **C. 장기** | 공지 번역 언어 확대(베트남어·중국어), 상시 번역 서버, 학생 피드백, 지속적 RAG 평가(CI), 유료 인프라(필요 시) |
