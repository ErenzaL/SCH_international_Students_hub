# 발표 요약 — SCH 국제학생 허브: 다국어 RAG와 AI 오피스

측정일 2026-11-27, 대학 GPU 워크스테이션(RTX 4070). 모든 숫자는 저장소의 결과 파일(`scripts/benchmarks/results/`)에서 나온 것입니다.
**주의:** 평가 질문과 정답 표시는 AI 보조 도구가 작성했고 사람이 검수하지 않았습니다. 따라서 숫자는 "AI가 작성한 정답과의 일치도"입니다.

## 1. 문제

- 순천향대 외국인 유학생은 비자·수강신청·기숙사·보험·취업에 대해 한국어, 영어, 인도네시아어, 베트남어, 중국어로 질문합니다.
- 공식 자료는 대부분 한국어·영어이고, 공지는 자주 바뀝니다.
- 일반 챗봇은 그럴듯한 수수료나 마감일을 지어냅니다. 출처 없이 대답한 로컬 모델은 합성 질문에서 **0 %** 정답이었습니다.

## 2. 왜 RAG인가

| 학생에게 필요한 것 | 일반 챗봇 | 허브의 RAG |
|---|---|---|
| 이 학교의 현재 수수료·마감일 | 추측 | 승인된 문서에서 인용 |
| 공식 정보인지 확인 | 출처 없음 | 모든 답변에 승인 문서 인용·원문 링크 |
| 바뀐 규정 | 학습 시점에 고정 | 현재 승인 버전만 검색, 이전 판은 표시 |
| 모를 때 | 그래도 답함 | 거절하거나 가장 가까운 출처만 제시 |
| 직원의 통제 | 없음 | 사람이 승인한 버전만 검색 가능 |

## 3. 시스템

질문(5개 언어) → 비자 코드·용어 분석 → 밀집 검색(multilingual-e5-small, int8) + 키워드 검색 + **개념 다리**(질문 속 용어를 공식 한국어·영어로 추가 검색)
→ 가중 결합, 비자 코드 불일치 감점, 최신 판 우선, 중복 공지 1회만 → 상위 10개 문단 → 답변 모델(운영: Gemini, 실험: 로컬 Qwen 2.5 7B)
→ 인용 확인·답변 언어 확인. 무료 Render(512 MB, CPU 0.1)에서 동작하도록 설계.

## 4. 검색 결과 (처음 보는 100문항, held-out)

| 구성 | Recall@1 | Recall@10 | MRR@10 [95 % 구간] |
|---|---|---|---|
| 벡터 검색만 | 0.50 | 0.83 | 0.631 [0.551–0.708] |
| 이전 하이브리드(main) | 0.47 | 0.82 | 0.601 [0.521–0.680] |
| **현재 운영 구성** | **0.63** | **0.94** | **0.736 [0.663–0.807]** |

- 벡터 검색 대비 **MRR +0.104** (짝지은 부트스트랩 95 % 구간 +0.045 ~ +0.164) → 개선이 우연이 아님.
- 개념 다리 단독 효과는 held-out에서 유의하지 않음(+0.009, 구간이 0을 포함) → 효과를 주장하지 않음.
- 개발용 질문(0.848)보다 처음 보는 질문(0.736)이 낮음 → 숫자는 held-out을 인용.

## 5. 약점 (오류 분석)

- **긴 일반 가이드북이 구체적 문서를 밀어냄**: 1위 오답의 대부분이 "외국인학생취업관련 정보", "한국 유학생 생활 가이드북" 등 긴 문서.
- 그 결과 **비자·체류 질문 Recall@1 0.30**, **한국어 질문 MRR 0.505**가 가장 낮음.
- 그래도 정답 문서는 모델이 읽는 10개 문단 안에 **94 %** 포함 → 답변 단계에서 상당 부분 회복.
- 다음 실험(사전 등록): 재순위 모델과 긴 문서 감점을 **새** 평가 세트에서, 짝지은 구간이 0보다 클 때만 채택.

## 6. 답변 결과 (합성 문서 95문항, 5개 언어, 규칙 기반 채점)

| 방식 | 정답률 [95 % 구간] | 답할 수 없는 질문 거절 | 오래된 수치 |
|---|---|---|---|
| **Qwen + RAG** | **91.6 % [84.3–95.7]** | **100 %** | **0 / 95** |
| 원문 발췌만(모델 없음) | 87.4 % | 60 % | 2.4 % |
| 출처 없는 Qwen | **0 %** | 0 % | – |

- 답변 언어는 95/95 모두 질문 언어와 일치.
- 이전 두 번의 실행(92.6 %, 91.6 %)과 같은 결과 → 재현 가능.
- 운영 모델 **Gemini + RAG는 측정하지 않음**(비용 승인 필요, 1회 약 US$0.28–0.46 예상).

## 7. 공지 번역 (Release 1: 한국어·영어·인도네시아어)

- 실제 SCH 공지 36개(개발 26 + held-out 10), 한→영, 한→인니, 총 72개 번역.
- 비교: Qwen 2.5 7B vs Google **TranslateGemma** 4B/12B, 허브 프롬프트(용어·날짜 힌트+최대 2회 수정) vs 모델 고유 프롬프트.
- 사전에 정한 규칙으로 **TranslateGemma 12B + 허브 프롬프트** 선택 → held-out **20/20** 초안에서 측정 오류 없음(Qwen 17/19, 1건 실패).
- 72개 전체에서 날짜·금액·링크 모두 보존, 사실 오류 1건(Qwen 6건 + 실패 1건). 차이는 표본이 작아 통계적으로 유의하지 않음(p = 0.25~0.38).
- 흥미로운 결과: TranslateGemma 고유 프롬프트보다 **허브의 힌트·수정 단계가 더 중요**(12B: 50/52 vs 42/52).
- 유창성은 측정하지 않음 → 모든 초안은 해당 언어 검수자가 승인해야만 학생에게 보임.

## 8. 비용과 신뢰성 장치

- 일일 AI 예산이 데이터베이스에 저장되어 **재시작해도 초기화되지 않음**, 백그라운드 작업은 시도마다 검사.
- 가격을 설정하면 비용 추정, 백그라운드 일일 비용 상한, 관리자 **긴급 중지** 버튼(챗봇은 계속 동작).
- 기회(장학·채용) 정보는 **읽는 순간** 한국 시간 기준으로 마감을 계산 → 마감 다음 날 즉시 사라짐, 날짜 없는 "모집 중"은 "마감일 미확인".

## 9. 한계

- 정답 표시가 사람 검수 전, 말뭉치 27개 문서로 작음, 운영 모델 **Gemini + RAG는 아직 측정하지 않음**(개발 서버에 키 없음).
- 지연 시간은 워크스테이션 기준이며 Render 실제 지연이 아님.
- 실제 학생 질문이 아닌 AI 작성 질문.

## 10. 한 줄 결론

> 승인된 공식 자료만 검색하는 다국어 하이브리드 RAG는 처음 보는 질문에서 벡터 검색보다 유의하게 정확했고(MRR 0.631 → 0.736),
> 출처 없는 모델이 0 %였던 질문에 근거 있는 답을 했습니다. 남은 과제는 사람 검수, 한국어·비자 질문, 그리고 Gemini 실측입니다.
